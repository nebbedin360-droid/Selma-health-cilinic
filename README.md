# Selam Health Clinic – Website

Static website (HTML + CSS + small JS). No build step required.

## Structure
- `index.html` – the full one-page site
- `assets/css` – styles and fonts
- `assets/js` – menu / contact button script
- `assets/images` – photos and logo

## Publish on GitHub Pages
1. Upload everything in this folder to a GitHub repository (keep `index.html` at the top level).
2. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. Your site will appear at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

_Concept project – the clinic, doctors and contact details are fictional._
